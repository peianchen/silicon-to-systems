# 教材交付前檢查紀錄

查核日期：2026 年 10 月 22–25 日。此紀錄說明檢查範圍、實際修正與剩餘限制，不是學術認證或產品安全保證。

## 交付範圍

46 章繁體中文正文、3 個附錄，涵蓋數理、電路、場、半導體元件、製程、品質、類比與數位系統、實驗專題及微奈米生醫感測。每章有學習目標、先備、模型說明、例題與至少兩道附解答練習。這是跨學科入門與銜接教材，不代表完整大學學位的全部深度。

提供分章 HTML、整本閱讀列印版、離線 ZIP、合併 Markdown 及可重建來源。離線閱讀不需要 CDN；外部參考文獻連結仍須網路。離線包已移除指向自身 ZIP 的無效下載連結。

作者組與主編對最終落地稿進行分工及交叉校閱，主要計算另用 JavaScript 重算。這些是本次編寫流程內的檢查，不是外聘學科專家或期刊同儕審查。

實際修正包括：常值激勵才可直接使用單指數終值式；轉移函數需零初始條件；電性接面須區分活化與化學濃度；完整週期 RMS 才可直接計通道平均損耗；CVD 通量需轉換成厚度速率；毛細壓力需指定幾何；良率相乘須銜接同一統計單位；源極退化會消耗電壓裕量；UART 主機停讀不自動形成背壓。

## 參考資料檢查

使用大學公開教材、期刊作者版、出版社書目與官方技術文件。課程索引用於學習路徑，不拿來假裝支持所有公式；完整課本未取得時，明列延伸閱讀。文獻年代、摘要查閱、公開節錄與全文查閱各自區分。

檢查中修正了誤連年報的 CMP 引用、失效的記憶體教育 PDF、舊版亞穩態頁與 ATPG PDF，並補入直接支持相應段落的 MIT、Stanford、Berkeley、Auburn 及 IEEE 資料。所有新增文字與例題獨立組織，沒有移植來源圖表；引用不表示來源作者背書或轉讓原權利。

全書引用另做 HTTP 可達性掃描。部分 IUPAC、RSC、Arm、設備商及學校網站回傳存取限制；部分 ADI、Microchip 或大學伺服器逾時。受限或逾時不直接等於永久失效，也不被記成全文查證通過。原始結果與替代紀錄保存在 research/reference-access.json。
