# 圖像設計規範：Silicon to Systems

版本：`sts-flat-v1`。2026-10-23 起適用於新繪或改繪的教材圖；現已套用第01單元八張及第02單元七張。第三章以後尚未完成同等圖解擴編，不表示已逐章驗收。

## 方向與界線

延續使用者選定的扁平工程示意語言，建立新教材自己的構圖、元件與標註。目標是風格相近，不是長得相同。不得複製參考圖的路徑、版面、數據圖案或細節，再稱為原創。

採純色幾何、規則對齊、深淺藍層次、少量橘色重點、圓形編號。不用寫實材質、光澤、陰影、虹彩或裝飾性假電路。同一單元可有流程、剖面、物件比較、曲線與系統方塊圖；一致的是視覺語言，不是每張都用同一版面。

## 共用規格

| 項目 | 規則 |
|---|---|
| 格式 | 示意與說明圖優先SVG；照片須有實際來源及使用權，不能偽裝成示意圖的量測證據 |
| 畫布 | 標準寬1200，高度依內容；零起點viewBox、明確width及height；白底適用淺深閱讀主題及列印 |
| 色盤 | 機器可讀的允許色在figure-style.json；深藍結構、淺藍材料／功能、橘色限定重點 |
| 橘色語意 | 每個分圖內定義清楚。選取、光阻、接點、異常等不能靠顏色猜；須有圖例或圖說 |
| 線條 | 主要輪廓約2px，輔線1–1.8px；純色、少量小圓角；資訊關係虛線、主流程實線並於圖說交代 |
| 字體 | Noto Sans CJK TC，依序回退CJK SC、DejaVu Sans、sans-serif；數字徽章可用Arial |
| 字級 | 標題25px、主要標籤22px、圖內輔註至少18px；必要縮寫至少20px；長解釋移到正文 |
| 標註 | 物件細部優先數字＋外部圖說；流程與系統可保留必要短詞，避免整段文字卡片 |
| 編號 | 藍灰圓底、白色粗體數字；同張的對象與分圖編號須可辨識 |
| 可及性 | 非空title、desc與Markdown替代文字；用位置、文字及形狀補足色彩，不只靠紅綠辨識 |
| 縮放 | 可點開原尺寸；同一比較圖保持幾何基準一致，非比例與局部放大必須明示 |

## 科學表達

- 先列教學目的、必畫結構、箭頭含義、假設及省略項，再作圖。
- 物件層級不是製程步驟；模型層級不是實體剖面。
- 概念剖面不可暗示準確厚度、完整佈線或特定廠商製程；圖說寫明。
- 曲線和晶圓圖要分清實測、計算與自設示意。沒有資料就不畫成實測結果。
- 軸、單位、圖例、取樣條件、公式假設依圖的用途提供，不為美觀省略。
- 相鄰製程剖面固定基板位置，清楚表示新增、移除或改變的材料。
- 返工和品質處置只畫已說明的條件；資訊回饋不等於實物可倒退恢復。

## 製作與驗收

1. 從本章內容建立新的布局與幾何，不從他人圖檔複製座標。
2. 取用figure-style.json色盤；SVG根元素加入 `data-figure-style="sts-flat-v1"`。
3. 同步Markdown替代文字、數字對照與圖說；保留資料來源和必要授權紀錄。
4. 逐張渲染檢查文字、箭頭、重疊、尺寸與科學意義。
5. 執行 `npm run build`、`npm run check`，確認單章、合冊、原尺寸圖與離線ZIP一致。
6. 用同一套規範接續下一單元；風格變更須先取得使用者方向，不能自行換成另一種視覺語言。

目前十五張成品可作規範範例，但不要把相同構圖硬套到不同教學問題。第01單元來源／修訂過程見unit-01-editorial.md；時間分配圖使用完整週期與局部放大兩種明示時間尺，色塊高度不代表電流。第02單元見unit-02-editorial.md；曲線依明示公式計算，線性升壓、RC指數響應與取樣插值不能混為同一過程。新增需求追溯及RC誤差門檻圖見unit-01-02-professional-review.md；不可把模型預測、待補量測或最不利參數曲線畫成已取得的實測與信賴區間。
